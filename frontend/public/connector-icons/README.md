# Connector logos

These logos identify the external system each connector talks to. Every
logo is a trademark of its owner. It is shown only to identify that system,
and its use does not imply any affiliation with, or endorsement by, that owner.

Don't use these files in marketing, on the website, or anywhere that suggests
a partnership or certification with the brand owner.

### Open item

Microsoft publishes the Azure icon set for architecture diagrams and
documentation. Check that its terms cover use inside a product UI. If they
don't, replace `adls.svg`, `eventhub.svg` and `synapse.svg` with neutral
icons or Simple Icons equivalents.

Record the source of every logo you add or replace in the table above.
